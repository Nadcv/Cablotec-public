# Cablotec – aplicação instalável

Página publicada no GitHub Pages que abre a aplicação **Cablotec – Relatórios, Controlo
de Produção & Checklist** (servidor no Google Apps Script, código no repositório privado
`cablotec-app`) em ecrã inteiro, com o ícone e o logótipo da Cablotec.

- Endereço: https://nadcv.github.io/Cablotec-public/
- iPhone: abrir no Safari → Partilhar → "Adicionar ao ecrã principal".
- Android: abrir no Chrome → menu ⋮ → "Instalar aplicação".

Não contém dados nem código do servidor: só o ecrã de entrada, o ícone e o endereço
público da aplicação.
